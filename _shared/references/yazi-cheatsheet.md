# yazi 基本操作速查（中文）

> 这份速查表供 skill 在 Phase 6b 向用户讲解使用。**用中文呈现核心键位即可，不要一次性全倒给用户。** 任何时候在 yazi 里按 **`~` 或 `F1`** 都能打开完整快捷键帮助。
>
> 以下为 yazi 默认键位（基于官方默认 keymap）。

## 移动 / 导航
| 键 | 作用 |
|---|---|
| `k` / `j` | 上移 / 下移光标（方向键 ↑ ↓ 同样可用） |
| `h` / `l` | 返回上级目录 / 进入目录（或打开文件） |
| `gg` / `G` | 跳到列表顶部 / 底部 |
| `H` / `L` | 浏览历史的后退 / 前进 |

## 选择（配合多选才像资源管理器批量操作）
| 键 | 作用 |
|---|---|
| `空格` | 选中当前项并下移一行 |
| `v` / `V` | 进入 / 退出 visual 多选模式（像 vim 选一段） |
| `Ctrl+a` | 全选 |
| `Ctrl+r` | 反选 |

## 复制 / 剪切 / 粘贴 / 删除
| 键 | 作用 |
|---|---|
| `y` | 复制（yank） |
| `x` | 剪切（cut） |
| `p` | 粘贴 |
| `P` | 粘贴并覆盖（目标已存在时直接覆盖） |
| `Y` / `X` | 取消复制 / 剪切标记 |
| `d` | 删除到回收站 |
| `D` | 永久删除（不进回收站，谨慎） |

典型流程（把几个文件移走）：`空格` 逐个勾选 → `x` 剪切 → 用 `h`/`l` 导航到目标目录 → `p` 粘贴。复制就把 `x` 换成 `y`。

## 新建 / 重命名 / 隐藏文件
| 键 | 作用 |
|---|---|
| `a` | 新建：名字结尾带 `\` 表示建文件夹，否则建文件 |
| `r` | 重命名（多选时会用编辑器批量重命名） |
| `.` | 显示 / 隐藏 隐藏文件 |

## 打开
| 键 | 作用 |
|---|---|
| `回车` 或 `o` | 用默认方式打开 |
| `O`（大写） | 选择打开方式（Open with，类似右键“打开方式”） |

预览会自动显示在右栏（图片、PDF、文本等）。

## 搜索 / 跳转 / 过滤
| 键 | 作用 |
|---|---|
| `/` / `?` | 向下 / 向上搜索 |
| `n` / `N` | 跳到下一个 / 上一个匹配 |
| `s` | 按文件名搜索（用 fd） |
| `S` | 按文件内容搜索（需要 ripgrep） |
| `f` | 在当前目录内过滤 |
| `z` / `Z` | 用 fzf / zoxide 快速跳转（需 PATH 里有 fzf / zoxide） |

## 标签页
| 键 | 作用 |
|---|---|
| `t` | 新建标签页 |
| `1`–`9` | 切换到第 n 个标签 |
| `[` / `]` | 上一个 / 下一个标签 |

## 任务 / 退出
| 键 | 作用 |
|---|---|
| `w` | 查看后台任务进度（复制/删除是异步执行的） |
| `~` 或 `F1` | 打开完整快捷键帮助 |
| `q` | 退出 |
| `Q` | 退出且不切换目录（配合 `y` 包装命令时有区别） |

> 如果装了 Phase 6c 的 `y` 快捷命令：用 `y` 启动 yazi，按 `q` 退出时 PowerShell 会切换到你最后浏览的目录；按 `Q` 退出则停在原地。

安装套件还会准备 `7zip`（压缩包）、`resvg`（SVG）、`ffmpeg`（视频）、`poppler`（PDF）、ImageMagick（图片）和 `jq`（JSON）等预览工具。
